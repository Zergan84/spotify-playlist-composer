# Spotify Playlist Composer 🎵

Минималистичный веб-сервис на **Cloudflare Workers** для быстрого создания плейлистов в Spotify из списка названий треков.

## 🚀 Возможности

1. **Авторизация по OAuth (Spotify PKCE)**:
   - Безопасный вход без передачи паролей.
   - Поддерживает стандарт PKCE (не требует client secret на клиенте).
2. **Медиатека пользователя**:
   - Отображение существующих плейлистов с обложками.
   - Характеристики каждого плейлиста: название, описание, количество треков, тип доступа (🔒 Закрытый / 🌐 Публичный), дата создания.
   - Быстрый переход в Spotify.
   - Поиск и фильтрация по названию.
3. **Генератор плейлистов по списку треков**:
   - Кнопка **«Создать плейлист»**.
   - Поле для ввода списка треков (построчно, например: `Queen - Bohemian Rhapsody` или `Daft Punk - Get Lucky`).
   - Настройка названия, описания и приватности плейлиста.
   - Автоматический поиск треков через Spotify Search API.
   - Отображение статуса поиска каждого трека в реальном времени.
   - Создание плейлиста в аккаунте пользователя и пакетное добавление найденных треков.
   - Прямая ссылка на готовый плейлист в Spotify.

## 🛠️ Настройка приложения в Spotify Developer Dashboard

1. Перейдите в [Spotify Developer Dashboard](https://developer.spotify.com/dashboard).
2. Нажмите **Create App**.
3. Укажите имя и описание, а в поле **Redirect URIs** добавьте:
   - Для продакшена: `https://spotify-playlist-composer.101filmstudio.workers.dev`
   - Для локальной разработки: `http://localhost:8787`
4. Сохраните приложение и скопируйте **Client ID**.
5. При первом открытии веб-сайта введите ваш Client ID (он сохранится в браузере), либо укажите его в `wrangler.json` в секции `vars.SPOTIFY_CLIENT_ID`.

## 💻 Локальный запуск

```bash
# Установка зависимостей
npm install

# Запуск локального сервера разработки
npm run dev
```

Локальный сайт будет доступен по адресу: `http://localhost:8787`

## ☁️ Деплой на Cloudflare Workers

### 1. Прямой деплой через CLI:
```bash
npx wrangler deploy
```

### 2. Автодеплой через GitHub Actions:
При пуше в ветку `main` запускается workflow `.github/workflows/deploy.yml`.
Для работы GitHub Actions добавьте секрет в репозиторий:
- `CLOUDFLARE_API_TOKEN` — токен Cloudflare с правами на Workers Scripts (Edit).
- `CLOUDFLARE_ACCOUNT_ID` (опционально, если не указан — используется `bdd893fdbdf00133bf4b777c19fa3096`).
